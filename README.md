# FleetOptima User Guide

The help guide shown inside the FleetOptima app. The app reads `guide.md` from this repo, so a change here shows up in the app without a new release.

How the app reads it:
- `## Heading` = a section that slides open
- `### Heading` = a subheading inside it
- everything else = the text
